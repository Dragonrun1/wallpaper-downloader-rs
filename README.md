# Readme

Wallpaper Downloader keeps your desktop fresh without getting in the way. It runs quietly in the system tray, downloads new wallpapers on a schedule, and changes your background automatically.

* Many sources: Bing Photo of the Day, DeviantArt, Dual Monitor Backgrounds, Social Wallpapering, Unsplash, Wallhaven and WallpaperFusion, each with its own schedule and rate-limit handling.
* Fits your setup: image-size filtering based on your actual screens, and options to change every monitor, one monitor, or use one image across all of them.
* You stay in control: keyword searches, forbidden tags, a download folder size limit that never touches your own files, and favorites and blocked images that are remembered.
* Polite to the services it uses: per-provider minimum intervals, backoff after failures, and Retry-After support, so it doesn’t hammer anyone’s servers.
* Light and native: a Rust and Slint app that stays in the tray and uses little memory while idle.
